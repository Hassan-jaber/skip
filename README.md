# SKIP® — الصفحة الرئيسية

موقع تعريفي لوكالة تسويق رقمي، عربي بالكامل (RTL)، مبني بـ HTML/CSS/JS خام — بدون إطار عمل أو اعتماديات خارجية.

بنية الصفحة وإيقاعها البصري مستوحاة من تجربة **rubaspace.com** (ترتيب الأقسام، البطل الفوتوغرافي كامل العرض، رؤوس الأقسام الموسّطة، شبكة الأعمال، القسم الداكن المتباين، الفوتر) — مع هوية SKIP ومحتواها وصورها بالكامل.

## التشغيل

```bash
python -m http.server 8000
```

أو افتح `index.html` مباشرة. `skip-standalone.html` هو نفس الصفحة كملف واحد مستقل (كل شيء مضمّن) للمعاينة السريعة أو الإرسال.

## البنية

```
index.html                  الصفحة (سيمانتيك + RTL)
assets/css/style.css        نظام التصميم كامل — متغيّرات في :root
assets/js/main.js           الهيدر، تبديل الشعار، القائمة، الكشف عند التمرير، النموذج
assets/fonts/*.woff2        29LT Bukra — Light 300 / Regular 400 / Bold 700
assets/img/*.webp           صور الأقسام
assets/img/logo-red.png     الشعار الملوّن — للخلفيات الفاتحة
assets/img/logo-white.png   الشعار الأبيض — للخلفيات الداكنة والصور
```

## الأقسام

| # | القسم | الخلفية |
|---|---|---|
| 1 | الهيدر | شفاف فوق البطل ← أبيض ضبابي عند التمرير |
| 2 | البطل | صورة فوتوغرافية كامل العرض + تدرّج نبيتي |
| 3 | من نحن | فاتح — نص يمين، صورة يسار، أرقام |
| 4 | خدماتنا | رملي `--sand` — ٤ بطاقات بيضاء |
| 5 | أعمالنا | فاتح — شبكة ٣×٢ بصور حقيقية |
| 6 | لماذا نحن | نبيتي `#85151D` — ٤ بطاقات |
| 7 | بيان العلامة | أحمر `#EF1C25` |
| 8 | تواصل معنا | رملي — نص وصورة يمين، نموذج يسار |
| 9 | الفوتر | نبيتي داكن `#5E0D13` |

## تبديل الشعار تلقائيًا

`main.js` يراقب موضع التمرير: ما دام الهيدر فوق صورة البطل الداكنة يظهر **الشعار الأبيض** بنص أبيض، وبمجرد تجاوز البطل يتحوّل إلى **الشعار الأحمر** بنص داكن. الشعاران موجودان في الـ DOM ويتبادلان الـ opacity — لا وميض ولا تحميل متأخر. الأقسام الداكنة (لماذا نحن، بيان العلامة، الفوتر) تستخدم الشعار الأبيض دائمًا.

## نظام التصميم

كل القيم متغيّرات CSS في `:root`:

| المتغيّر | القيمة | الاستخدام |
|---|---|---|
| `--red` | `#EF1C25` | الأزرار الأساسية، التأكيدات، قسم بيان العلامة |
| `--bur` | `#85151D` | قسم «لماذا نحن»، الأزرار الثانوية، العناوين الصغيرة |
| `--bur-dk` | `#5E0D13` | الفوتر وقائمة الجوال |
| `--yel` | `#FFE62C` | لمسات صغيرة فقط: تسميات الأقسام، فئات المشاريع |
| `--paper` / `--sand` | `#FCFAF9` / `#F3EDEA` | الخلفيات |
| `--ink` | `#1B1315` | النص — الأسود غير مستخدم كخلفية إطلاقًا |
| `--maxw` / `--pad` / `--sect` | `1280px` / `clamp()` / `clamp()` | العرض والهوامش وارتفاع الأقسام |

## ما يجب استبداله قبل الإطلاق

كل موضع معلّم بتعليق `<!-- ملاحظة: ... -->` داخل `index.html`:

1. **الأرقام** (`+50 / +20 / +5`) في البطل وقسم «من نحن» — أرقام مبدئية للعرض.
2. **مشاريع قسم «أعمالنا»** — الأسماء والفئات والصور نماذج، استبدلها بأعمال حقيقية.
3. **بيانات التواصل** — لم تُضَف أي بيانات مُختلقة. أضف البريد/الهاتف/العنوان في `.contact__body`.
4. **روابط التواصل الاجتماعي** في الفوتر — كلها `href="#"`.
5. **نموذج التواصل** — يتحقق من الحقول ويعرض رسالة نجاح فقط؛ اربطه بخدمة بريد أو CRM (`form` في `main.js`).

صور فوتوغرافية حقيقية من **Unsplash** (رخصة Unsplash — مجانية للاستخدام التجاري، دون الحاجة لإذن). محفوظة محليًا بصيغة WebP ليعمل الموقع دون اتصال:

| `work1.webp` | حملة رقمية | `photo-1633533451638-32f1e337d254` |

## ملاحظات تقنية

- متجاوب على 1440 / 1280 / 1024 / 768 / 390 / 375 دون تمرير أفقي.
- يحترم `prefers-reduced-motion` — كل الحركات تُلغى.
- حالات تركيز واضحة، قائمة الجوال تُغلق بـ `Esc`، وروابط التنقل تتتبّع القسم الظاهر.
- الأداء: صور WebP (‏≈420KB إجمالًا)، خطوط WOFF2 (‏≈150KB)، `loading="lazy"` لما تحت الطيّة، صفر مكتبات خارجية.

## ترخيص الخط

**29LT Bukra** خط تجاري من 29LT. ملفات `.woff2` هنا مُحوّلة من ملفات `.otf` المرفقة.
تأكّد من امتلاك ترخيص **ويب (Webfont)** ساري قبل نشر الموقع على نطاق عام — ترخيص سطح المكتب لا يغطي الويب.
